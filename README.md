# Recipe Box

A dark, responsive React Recipe Box for saving recipes, ingredients, steps, tags, and cooking details in browser LocalStorage.

![Recipe Box preview](screenshot.png)

## Features

- Add, edit, duplicate, and delete recipes.
- Store ingredients, ordered steps, notes, tags, servings, and cooking times.
- Search by title, category, or tag.
- Filter by category and sort by newest, title, or category.
- Image fallback, confirmation modal, responsive layout, and refresh-safe LocalStorage.
- Fixed branded header, floating go-to-top button, and icon-only footer links.

## Tech stack

React, Vite, styled-components, CSS, LocalStorage, and React Icons.

## Run locally

```bash
npm install
npm run dev
```

Build with `npm run build` and deploy with `npm run deploy`.
